4.1 Prediction Task
The major problem is binary prediction at session-level:
With a prompted browser, domain metadata and declared intention
predict whether, at the time of the session, the user will later report that the session was drift.
The positive class is the label No, I drifted, which was provided as a self-report. The negative class is self-reported Yes label. Sessions
Continue (intentional) or Save for later are analyzed separately or not included in the binary task. The resulting
model gives back a probability of drift for each session. In Phase 2, crossing the frozen threshold makes a student eligible to the
prompt-versus-silent-control randomization; the probability is not considered to be an attention detection.

4.3 Baselines
DriftSense uses four baselines to assess prior to the main models:
(1) Time-threshold baseline. Predict drift if the length of a session is longer than a threshold set on validation set.
(2) Domain baseline. Estimate drift tendency per each domain based on only training data and classify validation or test
sessions with the frozen training derived rule.
(3) Intention-only logistic regression. Predict only based on stated purpose and/or obvious text cues.
(4) Activity-only logistic regression. Predict from overall activity signals but no intention.
These baselines investigate whether the intention-plus-activity models proposed are useful in addition to common digital wellbeing models.
heuristics.
